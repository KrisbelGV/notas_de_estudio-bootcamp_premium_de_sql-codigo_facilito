Breve repaso en puntos clave:
	Siglas DBMS: Data Base Management System (en español “Sistema de Gestión de Bases de Datos”).
	Software encargado de procesar las sentencias SQL y cumple propiedades ACID. 
	DuckDB es un DBMS SQL analítico OLAP e In-Process de alto rendimiento.
	Instalar DuckDB:
		macOS: brew install duckdb
		Linux:
			Instalar el descompresor: sudo install unzip
			Descargar el archivo y descomprimirlo: curl --fail --location --progress-bar --output duckdb.cli_linux-amd64.zip https://github.com/duckdb/duckdb/releases/download/v1.1.3/duckdb_cli-linux-amd64.zip && unzip duckdb_cli-linux-amd64.zip
			./duckdb para ejecutarlo.
	SQLite en una biblioteca que implementa un DBMS transaccional y autónomo.
	Instalar SQLite:
		macOS: brew install sqlite No es necesario, viene preinstalado.
		Linux: sudo apt install sqlite3
	WSL es un subsistema de Windows que permite ejecutar un entorno GNU/Linux.
	Instalar WSL: wsl --install Requiere crear un usuario y contraseña tras finalizar.
	Comandos en terminal (para Linux):
		ls Listar archivos y directorios. .. retrocede un directorio.
		cd Cambiar el directorio.
		mkdir Crear directorio.
		code . Abrir VS Code en directorio actual.
