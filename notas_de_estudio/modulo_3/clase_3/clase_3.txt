Breve repaso en puntos clave:
	El álgebra relacional es un conjunto de operaciones estandarizadas sobre relaciones
	Una relación es una representación abstracta que conecta dominios.
	Se implementaron en un inicio en el lenguaje QUEL, evolucionado a SEQUEL, hoy SQL.
	Tabla comparativa (algebra relacional y SQL):
	+----------------------------------+---------------------+-----------+------------+--------------+
	| Operación del álgebra relacional | Producto cartesiano | Selección | Proyección | Natural Join |
	+----------------------------------+---------------------+-----------+------------+--------------+
	| Descripción                      | Combinación de las	 | Filtra    | Selecciona | Combinación  |
	|                                  | filas de una        | filas en  | columnas   | de filas con |
	|                                  | relación con otra   | una tabla |		  | atributos    |
	|                                  |                     |           |            | en común     |
	+----------------------------------+---------------------+-----------+------------+--------------+
	| Equivalencia en SQL              | OUTER JOIN/         | WHERE     | SELECT     | JOIN         |
	|                                  | CROSS JOIN          |           |            | (INNER JOIN) |
	+----------------------------------+---------------------+-----------+------------+--------------+

		LEFT JOIN: Mantiene los elementos de LEFT sumado los coincidentes de RIGTH.
			Sintaxis:
				SELECT *
				FROM tabla1
				LEFT JOIN tabla2
				ON tabla1.campo = tabla2.campo;
