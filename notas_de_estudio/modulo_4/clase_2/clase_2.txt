Breve repaso en puntos clave:
	Operadores del álgebra relacional (sus símbolos, descripción y equivalencia en SQL):
	+----------------------------------+--------------+---------------+------------------+-----------------+--------------+
	| Operación del álgebra relacional | Unión        | Intersección  | Diferencia       | Excepción       | Renombrado   |
	+----------------------------------+-------------.+---------------+------------------+-----------------+--------------+
	| Símbolo                          | ∪            | ∩             | -                | %               | ρ            |
	+----------------------------------+--------------+---------------+------------------+-----------------+--------------+
	| Descripción                      | Combinación  | Regresa las   | Regresa las      | Encuentra       | Renombra una |
	|                                  | de todas     | filas comunes | filas que se     | valores en      | tabla o sus  |
	|                                  | las filas    | entre ambas   | encuentran en    | una tabla que   | columnas     |
	|                                  | de tablas    | relaciones    | la primera tabla | se asocian con  | (atributos)  |
	|                                  | (relaciones) |               | pero no en       | todos los       |              |
	|                                  |              |               | la segunda       | valores en otra |              |
	+----------------------------------+--------------+---------------+------------------+-----------------+--------------+
	| Equivalencia en SQL              | UNION        | INTERSECT     | EXCEPT           | NOT EXISTS      | SELECT       |
	|                                  |              |               |                  |                 | {columna}    |
	|                                  |              |               |                  |                 | AS           |
	|                                  |              |               |                  |                 | nuevo_nombre |
	+----------------------------------+--------------+---------------+------------------+-----------------+--------------+
