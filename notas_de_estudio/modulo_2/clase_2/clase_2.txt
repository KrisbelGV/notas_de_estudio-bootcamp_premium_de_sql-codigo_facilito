Breve repaso en puntos clave:
	ALTER TABLE puede:
		Modificar columnas: ADD COLUMN
		Modificar tipos de datos: MODIFY COLUMN
		Eliminar columnas: DROP COLUMN
		Cambiar nombres de columnas CHANGE COLUMN
	Previo a eliminar es importante comprobar si existen dependencias.
	Contar caracteres de una cadena: CHAR_LENGTH()
	Desactivar restricción que protege de modificaciones a las tablas con datos sensibles a cambios: SET SESSION SQL_MODE = REPLACE(@@sql_mode, 'STRICT_TRANS_TABLES', '')
	Eliminar tabla si existe: DROP TABLE IF EXISTS tabla
	DELETE genera un log por cada eliminación, el espacio liberado no se devuelve automáticamente al sistema.
	TRUNCATE no genera log eliminando, resetea valores AUTO_INCREMENT y el espacio liberado se devuelve al sistema inmediatamente.
	DROP elimina la estructura por completo sin retorno.
	Transacciones:
		Crear una transacción: START TRANSACTION
	Restaurar datos de una transacción (si deja log): ROLLBACK
	Confirmar cambios (sin vuelta atrás): COMMIT
	Archivos de logs (en MySQL):
		* .ibd Contiene datos de la BDD
		* .log Contiene logs de transacciones
		Mostrar su ubicación: SHOW VARIABLES LIKE ‘datadir’
		Mostrar nombre del archivo .log: SHOW VARIABLES LIKE 'general_log_file'
	TIMESTAMP, DATETIME y DATE son diferentes tipos de dato para fecha y hora (abordados en la próxima clase).
	CURRENT_TIMESTAMP y NOW() obtienen la fecha y hora actuales.
	Crear un backup de una tabla: CREATE TABLE backup AS SELECT * FROM tabla
