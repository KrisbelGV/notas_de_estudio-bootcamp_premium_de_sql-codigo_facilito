Breve repaso en puntos clave:
	Conversiones de tipo (en PostgreSQL):
		Fecha a texto formateado: TO_CHAR(fecha, ‘formato’)
		Texto a fecha: TO_DATE(texto, ‘formato’)
	Los resultados de una función de agregación requieren una CTE para emplearse en WINDOWS FUNCTION.
	El producto de una WINDOWS FUNCTION solo puede ser filtrado en una consulta externa.
	Numerar registros:
		Compartir lugar si son iguales: RANK()
		No considerar empates: DENSE_RANK()
			La presencia de ORDER BY en la WINDOWS FUNCTION es obligatoria.
